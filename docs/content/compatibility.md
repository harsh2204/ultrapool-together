# Versions and troubleshooting

**Together v0.12.0 requires Ultrapool 0.17.2.** Everyone in the room needs v0.12.0 and a new **UP12** room code. Older Together versions cannot join these rooms.

[Download v0.12.0 and read its release notes](https://github.com/harsh2204/ultrapool-together/releases/tag/v0.12.0).

## We can’t join the same room

- Keep Steam running on every computer.
- Open Together before accepting an invitation.
- Check that everyone installed the same release.
- Create a fresh room after updating, and share the new code.
- Use the installed **Launch.cmd** or **Launch.command** to open the mod.

The Steam overlay is optional; you can invite friends from the in-game list or use a room code.

## Steam updated Ultrapool

Check for a matching Together update, then rerun its installer. Start a fresh run after updating. Older unfinished runs may no longer work, but their save files are kept.

## What can we play?

Together supports standard runs. Daily challenges and Creative multiplayer aren’t supported.

New players join between matches. If a table’s host disconnects, that table ends. If the room host leaves, the whole room closes; another player can’t take over hosting.

Together is still experimental. Online play, busy shared shops, and games between Windows and macOS players need more playtesting.

## Something else went wrong

[Report an issue](https://github.com/harsh2204/ultrapool-together/issues) with your Together version, Windows or macOS version, and what you were doing. A screenshot of the error helps.
