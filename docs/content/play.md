# Play together

Bring **2–8 players**. Share one table for co-op, or split into teams. Each table has its own run and shop.

The player who creates the lobby is the **room host**. The player in the first occupied seat at each table is its **table host**.

## Start a match

1. Open Together with Steam running. Press **F8 → Create lobby**.
2. Invite friends or share the room code.
3. The host chooses the number of tables. Everyone votes for a starting set, difficulty, and match mode.
4. Join a table and choose **Ready up**.
5. When everyone is ready and every table has a player, the host chooses **Start match**.

Changing seats, settings, or votes clears readiness. **No preference** skips a vote. The most votes wins; ties follow the displayed option order. All tables start with the same setup.

## Match modes

| Mode | The goal |
| --- | --- |
| **Co-op** | Share one run, wallet, and inventory. |
| **Race** | Finish the full run first. Other tables can keep playing for their finishing place. There’s no shot cap. |
| **Score PvP** | Score the most with the same shot limit: six by default, or 1–20 chosen by the host. An early loss also ends that table’s match. |

Uneven teams work too: try 2v1 or 1v1v1v2.

## Turns and shopping

Teammates take turns in seat order. **Pass** hands over the turn without using a shot. You can see your teammate’s cursor and aim.

After the round payout, choose **Continue** to shop. Everyone at the table can buy and arrange items. Every teammate must choose **Ready** before leaving. Purchases and rearrangements clear readiness. [Shopping together](shared-shop.md).

## Spectating

Press **F8 → Watch** to visit another table. Switch tables or return to your own whenever you like. A table in the shop shows its last board.

## Play another match

The host can return everyone to the lobby once all tables finish. Ending a match early needs everyone’s approval. Your seats stay assigned for the next match.

New players join between matches. If a table’s host disconnects, that table ends; if the room host leaves, the room closes.
