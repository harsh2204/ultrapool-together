# Expansion sets

Six optional sets add new balls to the shop. The host chooses which ones to use before the match: open **Mod settings**, enable **Expansion sets**, then pick your sets.

They start off by default. Enabling a set adds occasional shop offers; your starting rack and starting-set votes stay the same.

## Choose a set

| Set | How it plays |
| --- | --- |
| **Phases** | Each ordinary ball you pot advances the moon phase. Time your shots to collect bonuses during New, Waxing, Full, or Waning. |
| **Morph** | Cue-ball hits switch balls between forms. Change a ball’s form before potting it to use a different effect. |
| **Tide** | Cushion hits raise the tide; pots lower it. Some balls prefer calm water, while others reward a high tide. |
| **Relic** | Build up dig charges through shots and cushion hits, then cash them in when you pot. Some relics help charge the others. |
| **Tarot** | Up to three cards form your spread each round. Cushion hits flip them upright or reversed, changing their effects. |
| **Zodiac** | Collect signs with matching elements. Two form an Aspect; three or more form a Grand Trine and unlock stronger effects. |

## Build around a few favorites

Inspect a ball in the shop to read its effect before buying. Expansion balls use the usual buying, selling, arranging, and mixing controls.

Passing doesn’t charge their abilities. The host’s choices stay fixed for the match, so return to the lobby to change sets.

These sets still need playtesting. Try one or two at a time while you learn what they do.

For balls built around team turns, called pockets, and shared rewards, see the [Together set](multiplayer-balls.md).
